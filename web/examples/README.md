# Demo alignment files

Twenty in-frame codon alignments, two sequences each, for the "Load 20 example
files" button on the kaks web page. They are cut from the example data that
ships with PAML (Ziheng Yang, GNU GPL v3): ten primate lysozyme pairs from
`examples/lysozyme/lysozymeSmall.nuc` and all ten pairs of the five
alpha/beta-globin sequences in `examples/abglobin.nuc`. Standard genetic
code; use them with "Already an in-frame codon alignment" ticked.
